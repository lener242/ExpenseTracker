#  ExpenseTracker (FinTrack)

**ExpenseTracker (FinTrack)** — это современное веб-приложение для мониторинга личных финансов, анализа расходов и доходов, выстраивания бюджетов и визуализации статистики.

---

##  Технологический стек

* **Frontend:** Vanilla HTML5, CSS3 (Modern Fintech Theme)
* **Scripting / Logic:** JavaScript (ES6 Modules & DOM manipulation)
* **Data Visualization:** [Chart.js](https://www.chartjs.org/) (Интерактивные диаграммы)
* **Typography:** Plus Jakarta Sans (Google Fonts)

---

##  Структура проекта

```text
expense-tracker/
├── index.html   # Основная разметка приложения (sidebar, дашборды, модальные окна)
├── style.css    # Стилевое оформление (Fintech UI, адаптивная сетка, темы)
└── app.js       # Логика работы (расчеты, обработка событий, интеграция с Chart.js)
```

---

##  Основные возможности

* ** Наглядные отчеты и аналитика:** Круговые круговые диаграммы (Donut Chart) для быстрой оценки распределения расходов по категориям.
* ** Управление транзакциями:** Просмотр подробного списка операций с сортировкой по типу, категориям и датам.
* ** Динамический расчет категорий:** Автоматический перерасчет процентов, сумм и прироста к предыдущим месяцам.
* ** Лимиты и бюджетирование:** Возможность задавать и отслеживать месячные финансовые лимиты.
* ** Интерактивные модальные окна:** Удобные формы для добавления новых доходов, расходов и настройки бюджета.

---

##  Быстрый запуск

Проект написан на чистом Vanilla JS и не требует сложной сборки или установки дополнительных Node.js пакетов.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/ExpenseTracker.git
   cd ExpenseTracker/expense-tracker
   ```

2. **Запустите проект:**
   * Просто откройте файл `index.html` в любом современном веб-браузере.
   * Или используйте локальный сервер (например, плагин **Live Server** в VS Code).
